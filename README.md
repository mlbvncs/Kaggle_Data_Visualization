# Kaggle_Data_Visualization
Notebooks and datas from Kaggle Data Visualization course

### Resumo 
Como nem sempre é fácil decidir a melhor forma de contar a história por trás dos seus dados, dividimos os tipos de gráficos em três categorias principais para ajudar nessa tarefa.

1. Tendências - Uma tendência é definida como um padrão de mudança.

- **sns.lineplot:** Os gráficos de linhas são ideais para mostrar tendências ao longo de um período de tempo, e várias linhas podem ser usadas para mostrar tendências em mais de um grupo.

2. Relacionamento - Existem muitos tipos diferentes de gráficos que você pode usar para entender os relacionamentos entre as variáveis ​​nos seus dados.

- **sns.barplot:** Os gráficos de barras são úteis para comparar quantidades correspondentes a diferentes grupos;

- **sns.heatmap:** Os heatmaps (mapas de calor) podem ser usados ​​para encontrar padrões codificados por cores em tabelas de números;

- **sns.scatterplot:** Os gráficos de dispersão mostram o relacionamento entre duas variáveis ​​contínuas; se codificados por cores, também podemos mostrar o relacionamento com uma terceira variável categórica;
  
- **sns.regplot:** Incluir uma linha de regressão no gráfico de dispersão facilita a visualização de qualquer relação linear entre duas variáveis;
  
- **sns.lmplot**: Este comando é útil para desenhar múltiplas linhas de regressão, caso o gráfico de dispersão contenha múltiplos grupos codificados por cores;
  
- **sns.swarmplot** - Gráficos de dispersão categóricos mostram a relação entre uma variável contínua e uma variável categórica.

3. Distribuição - Visualizamos distribuições para mostrar os valores possíveis que podemos esperar ver em uma variável, juntamente com a probabilidade de ocorrência desses valores.

- **sns.histplot:** Histogramas mostram a distribuição de uma única variável numérica;
  
- **sns.kdeplot** Gráficos KDE (ou gráficos KDE 2D) mostram uma distribuição suave estimada de uma única variável numérica (ou duas variáveis ​​numéricas);
  
- **sns.jointplot** - Este comando é útil para exibir simultaneamente um gráfico KDE 2D com os gráficos KDE correspondentes para cada variável individual.
